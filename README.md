# Currency Converter

**Автор:** Шаяхметов Гадель 

## Описание программы
Приложение для конвертации валют с использованием API exchangerate-api.com. Сохраняет историю операций в JSON.

## Как получить API-ключ
1. Зарегистрируйтесь на exchangerate-api.com.
2. Получите бесплатный или платный API-ключ.
3. Вставьте ключ в переменную `API_KEY` в коде.

## Инструкция по запуску
1. Установите Python 3.x и библиотеку `requests` (`pip install requests`).
2. Вставьте свой API-ключ.
3. Запустите: `python currency_converter.py`
